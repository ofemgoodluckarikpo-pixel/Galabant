# GALABANT Fashion — Local Demo

An original HTML/CSS/JavaScript fashion storefront inspired by the publicly visible structure of the GALABANT demo site. It is a learning implementation, not the original site's source code.

## Run locally
1. Extract the ZIP.
2. Open the `GALABANT-local` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Product images and Google Fonts need an internet connection.

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — demo product cards, cart counter, search and newsletter interaction

Cart, search and newsletter interactions are frontend demos only; there is no backend or real checkout.
